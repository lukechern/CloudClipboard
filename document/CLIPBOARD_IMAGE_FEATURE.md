# 剪贴板图片功能

## 功能概述

云剪贴板现在支持从剪贴板粘贴图片，并在历史记录中显示图片缩略图。新增的图片专用模式提供了更简洁的纯图片上传体验。

## 新增功能

### 1. 图片粘贴支持
- 支持从剪贴板直接粘贴图片
- 支持常见图片格式（PNG、JPG、GIF、WebP等）
- 图片大小限制：5MB
- 自动转换为Base64格式存储

### 2. 图片预览
- 粘贴图片后立即显示预览
- 支持多张图片同时预览
- 显示图片类型和文件大小信息
- 可单独移除图片

### 3. 图片专用模式 ⭐ 新增
- 检测到剪贴板只有图片时，自动隐藏文本框
- 提供更简洁的纯图片上传体验
- 特殊的视觉样式突出图片预览
- 标题显示"准备发送图片到云端"
- 清除按钮显示文本"清除"
- 点击清除按钮可恢复正常模式

### 4. 混合内容支持
- 支持文本+图片的混合内容
- 智能模式切换：纯文本、纯图片、混合内容
- 文本和图片可以独立添加和清除
- 统一的提交和存储机制

### 5. 历史记录增强
- 历史记录中显示图片缩略图（80x60px）
- 点击缩略图可查看大图
- 支持图片下载功能
- 显示图片数量信息

### 6. 用户界面改进
- 新增"粘贴"按钮，支持一键粘贴剪贴板内容
- 清空按钮现在可以同时清除文本和图片
- 响应式设计，移动端友好
- 图片查看器模态框

## 使用方法

### 图片专用模式使用流程
1. 复制图片到剪贴板（右键图片 → 复制图像）
2. 在云剪贴板页面点击"粘贴"按钮或使用 Ctrl+V
3. 系统自动检测到纯图片，进入图片专用模式
4. 文本框自动隐藏，图片预览区域突出显示
5. 点击"发送到云端"直接保存图片
6. 或点击"清除"按钮恢复正常模式

### 混合内容使用
1. 在文本框中输入文字
2. 粘贴图片到预览区域
3. 系统保持混合模式，同时显示文本框和图片预览
4. 点击"发送到云端"保存文本和图片

### 查看历史图片
1. 在历史记录中找到包含图片的记录
2. 点击图片缩略图查看大图
3. 在查看器中可以下载图片

## 智能模式切换

系统会根据内容自动切换显示模式：

- **纯文本模式**：只有文本时的正常显示
- **纯图片模式**：只有图片时隐藏文本框，突出图片预览
- **混合模式**：同时有文本和图片时的完整显示

## 技术实现

### 前端
- 使用 Clipboard API 读取剪贴板内容
- FileReader API 将图片转换为Base64
- 智能检测内容类型，动态调整界面
- 响应式CSS实现图片预览和缩略图
- 模态框实现图片查看器

### 数据存储
- 图片以Base64格式存储在数据库中
- 混合内容使用JSON格式存储图片数组
- 内容类型标识：text（纯文本）、image（纯图片）、mixed（混合）
- 兼容现有的纯文本记录

### 浏览器兼容性
- 需要HTTPS环境才能访问剪贴板API
- 支持现代浏览器（Chrome 76+, Firefox 90+, Safari 13.1+）
- 移动端可能需要手动粘贴操作

## 样式特性

### 图片专用模式样式
- 预览容器使用特殊边框颜色（#667eea）
- 渐变背景突出显示
- 图片居中显示，尺寸更大
- 清除按钮显示文本标签
- 整体视觉更加突出

### 响应式设计
- 桌面端：图片最大300x200px
- 移动端：图片最大150x120px
- 按钮布局自适应屏幕尺寸

## 注意事项

1. **安全性**：图片以Base64格式存储，会增加数据库大小
2. **性能**：大量图片可能影响加载速度
3. **存储**：建议定期清理不需要的图片记录
4. **兼容性**：旧版本浏览器可能不支持某些功能
5. **用户体验**：图片专用模式提供更直观的上传体验
6. **表单验证**：系统会自动管理required属性，避免隐藏字段的验证错误
