剪贴板图片功能测试指南

🎯 新增功能

  • 支持从剪贴板粘贴图片
  • 图片专用模式：只有图片时自动隐藏文本框
  • 图片预览功能
  • 历史记录中显示图片缩略图
  • 图片查看和下载功能
  • 混合内容支持（文本+图片）
  • 纯图片模式：可直接发送图片到云端

🧪 测试步骤

1. 测试图片专用模式

• 复制一张图片到剪贴板（右键图片 → 复制图像）

• 返回主页面，点击"粘贴"按钮或使用 Ctrl+V

• 应该看到文本框隐藏，只显示图片预览

• 标题显示"准备发送图片到云端"

• 点击"发送到云端"可直接保存图片

2. 测试混合内容

• 在文本框中输入一些文字

• 再粘贴一张图片

• 点击"发送到云端"保存

3. 测试历史记录

• 查看历史记录中的图片缩略图

• 点击缩略图查看大图

• 测试图片下载功能

4. 测试清空功能

• 在图片专用模式下，点击"清除"按钮

• 应该清除图片并恢复文本框显示

• 在混合模式下，清空按钮同时清除文本和图片

⚠️ 注意事项

  • 需要HTTPS环境才能访问剪贴板API
  • 图片大小限制为5MB
  • 支持常见图片格式（PNG、JPG、GIF等）
  • 移动端可能需要手动粘贴

🔧 技术实现

  • 使用 Clipboard API 读取剪贴板内容
  • Base64 编码存储图片数据
  • 响应式图片预览和缩略图
  • 模态框图片查看器
